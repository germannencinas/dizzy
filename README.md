# Dizzy

Escribe tu banda favorita y te recomiendo una lista de bandas
similares que deberias escuchar.

React + Tailwind CSS

## API

```
browser ──> /api/similares ──> Last.fm      (bandas similares)
                             └─> MusicBrainz  (ciudad y país)
          ──> /api/deezer    ──> Deezer       (fotos de artistas)
```
